    # House Price Prediction Using Machine Learning

## Project Overview
A machine learning regression project that predicts residential sale prices using the Ames Housing Dataset. The project includes data analysis, preprocessing, feature selection, model training, and evaluation.

## Models
- Support Vector Regression (SVR)
- Random Forest Regressor
- XGBoost Regressor
- Stacking Ensemble using SVR, Random Forest, and XGBoost

## Key Features
- Exploratory Data Analysis (EDA)
- Missing Value Handling and Encoding
- Feature Selection
- Hyperparameter Tuning
- Data Leakage Prevention
- Comparison between Full and Reduced Feature Sets

## Best Results
- **Best Model:** Stacking Ensemble
- **Test RMSE:** $22,442
- **Test R² Score:** 0.927

## Technologies
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, XGBoost, Jupyter Notebook.

## Dataset
Ames Housing Dataset — 2,930 records and 79 original features.
